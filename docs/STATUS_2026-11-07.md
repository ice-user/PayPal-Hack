# Status note, 2026-11-07

## Done and verified
- **PayPal sandbox (Spike 1, partial).** Token works, with dispute scopes. A real dispute
  `PP-R-BTL-10196893` exists and reads back through the API. Seller actions are refused
  while it is `UNDER_PAYPAL_REVIEW`. Details: `docs/SPIKE1_RESULT.md`.
- **Contracts.** Schemas for SituationRecord, Recommendation, PolicyDecision, Case and
  ScreenBundle in `contracts/schemas`. Shared values in `contracts/thresholds.json`.
- **Case library seed.** 24 authored cases (6 per demo pattern plus fraud, listing and
  low-value distractors). All `illustrative`, no outcome numbers. The schema rejects an
  authored case that claims measured numbers.
- **Consultant** (`intelligence/consultant.py`). Precedents vote on interventions,
  weighted by similarity and evidence quality; fixed action templates; abstains below
  `k_min` or the confidence floor; the LLM hook may only rewrite prose.
- **Fixtures** for situations A, B, C in both modes, built by the real pipeline and
  validated. A: carrier failure; B: fulfilment delay; C: delivered-order evidence. The
  no-precedent baseline gives the same generic plan for all three, and the gate blocks it.
- **Frontend** on fixtures: situation, precedents (matched/differs, provenance and
  evidence badges), plan (tier and decision badges, approve/reject), timeline with
  simulated labels, situation switcher and with/without-precedent toggle. Checked in the
  browser at desktop and phone width; no console errors.
- **Tests:** 20 passing (`python -m pytest -q`). Frontend type-checks and builds.
